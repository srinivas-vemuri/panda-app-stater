🐼 Panda PHP Blank Boiler Plate Setup

🚀 Project Overview

Panda PHP is a lightweight, secure PHP boilerplate designed to kickstart rapid development of small to medium web applications. Built with procedural PHP and SQLite, it provides a solid foundation with essential features while maintaining simplicity and ease of use.

✨ Key Features & Systems

🔐 Authentication & User Management

  • Multi-tier User System:

    • Super Admin (2): Full system access + developer features

    • Admin (1): User management + basic settings

    • Regular User (0): Normal application access

  • Secure Session Management

  • Password reset with email verification

  • User activation/deactivation controls

🗄️ Database Architecture

  • SQLite Integration: File-based database for easy deployment

  • Auto-creation: Database and tables created automatically on first run

  • Unique User IDs: 6-character alphanumeric codes (not sequential)

  • Secure password storage with MD5 hashing

🌐 Progressive Web App (PWA) Ready

  • Dynamic Manifest Generation

  • Service Worker Setup

  • Mobile-responsive design

  • App-like user experience

📧 Email System

  • SMTP Configuration via admin settings

  • System Notifications for new registrations

  • Password reset functionality

  • Customizable email signatures

📁 PHP Pages Structure

🔓 Public Pages (No Authentication Required)

  • install.php - First-time system setup

  • login.php - User authentication

  • register.php - New user registration

  • forgotpassword.php - Password reset request (Step 1)

  • resetpassword.php - Password reset with code (Step 2)

🔒 Protected Pages (Authentication Required)

  • index.php - Main dashboard/homepage

  • changepassword.php - Password management

  • logout.php - Session termination

👑 Admin-Only Pages

  • usermanagement.php - User administration

  • useredit.php - User profile editing

  • settings.php - System configuration (Coming Soon)

📚 Include Files (Core System)

  • inc/config.php - Basic configuration

  • inc/functions.php - Core functions and authentication

  • inc/database.php - Database connection and setup

  • inc/email.php - Email handling utilities

  • inc/header.php - Protected page header

  • inc/footer.php - Page footer

🏁 First-Time Setup Process

Automatic Installation Flow

  1. Detection: System checks for data.sqlite on first access

  2. Redirect: Automatically redirects to install.php if database missing

  3. Super Admin Creation:

    • User provides email, password, and full name

    • System creates first user with user_type = 2 (Super Admin)

    • Default username: superadmin

  4. Database Initialization: Tables and default structures created

  5. Auto-login: Redirect to main application

Super Admin Capabilities

  • ✅ Create and manage other administrators

  • ✅ Activate/deactivate user accounts

  • ✅ Access all system settings

  • ✅ Developer features and advanced configurations

  • ✅ Full database management access

🛠️ Getting Started

Basic Setup

  1. Upload all files to your web server

  2. Ensure PHP has write permissions in the directory

  3. Visit your domain - system will auto-install

  4. Create your super admin account

  5. Start building your application!

Customization Points
