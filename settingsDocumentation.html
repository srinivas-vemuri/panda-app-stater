h1>Panda PHP Blank App - Settings System Documentation

Project Name: Panda PHP Blank App
Type: PHP Boilerplate/Starter System
Goal: Create a scalable, admin-configurable PHP application starter with PWA capabilities

Core Strategy

Settings Storage

  • File: settings.json in /inc/ directory

  • Auto-creation: File created automatically if not present

  • Structure: Grouped settings with validation and defaults

User Permission System

  • user_type 2 = super_admin (full system access + developer features)

  • user_type 1 = admin (user management + basic settings)

  • user_type 0 = regular (normal user access)

Settings Groups Structure

Group 1: Basic App Configuration

Core application identity and fundamental settings

Group 2: Branding & Design

Visual identity, logos, colors, and styling

Group 3: PWA Settings

Progressive Web App configuration and assets

Group 4: Email Configuration

SMTP settings and email functionality

Settings Fields Reference

Group 1: Basic App Configuration

Field Name Field Label Input Type Description Developer Notes
appname App Name Text The full name of your application, displayed in browser titles and app stores Use in HTML titles: <title><?= getSettingValue('appname') ?></title>
appshortname Short Name Text Compact name for mobile homescreens (maximum 12 characters) Used in PWA manifest. Access via getSettingValue('appshortname')
appurl App URL Text Your application's main domain URL Use for absolute URLs: <?= getSettingValue('appurl') ?>/path
appadminemail Admin Email Email Primary administrator email for system alerts and notifications Use for system notifications and contact forms
appfootertext Footer Text Text Copyright and legal text displayed in application footer Display in footer templates: <?= htmlspecialchars(getSettingValue('appfootertext')) ?>
appindexpage Index Page Text Starting page when users open the application Use for redirects after login

Group 2: Branding & Design

Field Name Field Label Input Type Description Developer Notes
appregularlogo Main Logo File Primary logo for login pages and larger displays (recommended: 400x400px PNG) Use: <img src="assets/logos/<?= getSettingValue('appregularlogo') ?>">
appheaderlogo Header Logo File Compact logo for navigation headers (recommended: 150x50px PNG) Use in navigation headers, ensure responsive scaling
appfevicon Favicon File Browser tab icon (recommended: 32x32px PNG) Auto-used in generated HTML, upload PNG format
appthemecolor Theme Color Color Primary brand color for browser UI and mobile address bars Apply as CSS variable: --primary-color: <?= getSettingValue('appthemecolor') ?>
appheadercolor Header Color Color Background color for top navigation header Apply as CSS variable for header styling
appfootercolor Footer Color Color Background color for application footer Use in footer section styling

Group 3: PWA Settings

Field Name Field Label Input Type Description Developer Notes
appispwa Enable PWA Checkbox Enable Progressive Web App features and functionality Check: <?php if(getSettingValue('appispwa')) { generatePWAFiles(); } ?>
appicon192 PWA Icon Small File 192x192px icon for Android homescreens Auto-used in manifest.json, must be exactly 192x192px
appicon512 PWA Icon Large File 512x512px icon for splash screens and larger devices Auto-used in manifest.json, generate splash screens from this
appdisplay Display Mode Select How the app appears when launched Options: standalone, minimal-ui, browser. Auto-set in manifest

Group 4: Email Configuration

appsmtpport SMTP Port Number Outgoing mail server port Used automatically, common ports: 587 (TLS), 465 (SSL)

Core Functions Architecture

Primary Functions
// Get settings by group or specific field
getSettings($group = null, $field = null)

// Quick value access with fallback to defaults  
getSettingValue($field)

// Bulk update settings with validation
updateSettings($updates)

// Secure file processing and storage
handleFileUpload($field, $file)

// Dynamic PWA file creation
generatePWAFiles()

Function Usage Examples

// Basic value retrieval
$appName = getSettingValue('appname');

// Group-based access  
$brandingSettings = getSettings('branding');

// File upload handling
$result = handleFileUpload('appregularlogo', $_FILES['logo']);

// PWA generation
if (getSettingValue('appispwa')) {
    generatePWAFiles();
}

Technical Implementation Details

JSON Structure

{
  "settings": {
    "basic": {
      "appname": {
        "value": "Panda PHP",
        "type": "text",
        "label": "App Name",
        "description": "Your application name",
        "developer_note": "Use in HTML titles"
      }
    }
  }
}

File Upload Strategy

  • Location: /assets/logos/, /assets/icons/

  • Naming: fieldname_timestamp.ext (e.g., main_logo_1705312800.png)

  • Sanitization: Lowercase, underscores, no special characters

  • Validation: File type and size checking

PWA File Generation

When appispwa = true, automatically generate:

  • manifest.json (from settings)

  • service-worker.js (basic caching)

  • Icon optimization and placement

Default Values & Fallbacks

$defaults = [
    'appname' => 'Panda PHP App',
    'appshortname' => 'Panda',
    'appurl' => 'http://localhost',
    'appispwa' => false,
    'appsmtpport' => 587
];

Settings Page UI Design

Tab-based Interface

  • Tab 1: Basic Settings - App Name, Short Name, App URL, Admin Email, Footer Text, Index Page

  • Tab 2: Branding - Logos (Main, Header), Favicon, Colors (Theme, Header, Footer)

  • Tab 3: PWA - Enable PWA checkbox, Icon uploads (192px, 512px), Display mode selection

  • Tab 4: Email - SMTP Settings (Host, Port), Credentials (Username, Password), Email signature

Developer Features

  • Syntax Highlighting: Prism.js for code examples

  • Developer Notes: Visible only to super_admins (user_type = 2)

  • Inline Help: Contextual developer usage examples
